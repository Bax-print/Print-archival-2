# Print Archival Theme Instructions

This is a custom classic WordPress theme for Print Archival.

Business structure:
- Print Archival = archival print studio and production service
- The Archive = curated marketplace / artist archive
- Tattoo Archival = tattoo-specific print lane
- Fine Art Printing = professional/private/gallery/wedding service lane

Important rules:
- Do not edit or request wp-config.php secrets.
- Do not hardcode private keys, passwords, API keys, or Google credentials.
- Do not remove the intake form system unless explicitly asked.
- Avoid duplicate PHP function names.
- Keep PHP compatible with WordPress classic theme structure.
- Use staging-safe changes first.
- Preserve the current navigation structure.
- Avoid WooCommerce changes unless specifically requested.

Current key feature:
- /submit-your-work/ intake form
- AJAX progress
- protected local staging
- Google Drive upload
- local file deletion after successful transfer
- email notification
- WordPress admin Intake Submissions log
